# Out of scope

What the product does not do.

| Out of scope | Origin |
|---|---|
| Crear, editar o eliminar personas, su habilitación o su asignación a proyectos: se cargan directamente en la base | initial |
| Crear o quitar permisos de proyecto de los usuarios: se cargan directamente en la base | initial |
| Dar de alta usuarios, cambiar sus roles o recuperar su acceso: lo hace el proveedor de identidad, y el producto solo refleja la identidad | initial |
| Eliminar clientes o proyectos | initial |
| Cerrar la sesión en el proveedor de identidad al cerrar la sesión de la aplicación | initial |
| Renovar una sesión cuando vence el token de acceso | initial |
| Limpiar archivos nunca vinculados, desvinculados de todo o cuya subida no terminó | initial |
| Compartir hacia afuera un adjunto de un requisito o de una tarea | initial |
| Preferencias de notificación (apagar avisos sin desuscribirse) | initial |
| Canales de notificación distintos del email (push, mensajería, webhooks) | initial |
| Notificaciones de tareas y suscripciones a tareas | initial |
| Notificar la edición de un comentario o los cambios de campo de un requisito que no son resolución ni reapertura | initial |
| Que las respuestas a un email de notificación vuelvan al producto | initial |
| Mostrar horas trabajadas en el Portal de clientes | initial |
| Ordenar el listado de requisitos por horas trabajadas | initial |
| Cola, reintento o idempotencia de los comandos: un comando que no obtiene respuesta no se reintenta | initial |
| Registro de auditoría de accesos | initial |
| Administrar carpetas y permisos de la documentación desde la interfaz | initial |
| Subir a la documentación contenido de más de 256 KiB desde la interfaz | initial |
| Actualización en tiempo real de la documentación en el navegador | initial |
| Editar, buscar en toda la documentación o compartir documentos desde el Portal de clientes | initial |
| Búsqueda semántica en la documentación | initial |
