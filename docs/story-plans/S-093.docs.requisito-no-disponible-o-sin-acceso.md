### Discrepancia

- **D-1 — "global de queryClient".** La story (DD-9) y el comentario de `useRequirement.ts:16-17` citan el

  configuración que corre es la de `providers.tsx:20`. Los dos valen `1`, así que el comportamiento es el
  descripto. La arquitectura se escribe contra `providers.tsx` (lo que corre); el comentario del código
  no se toca (no es de esta fila).
