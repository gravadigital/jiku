### API Context: el contrato a copiar

#### La única línea que cambia (línea 65 del origen)

Antes (origen, verbatim):

```yaml
  registerModule:
    action: send
    channel: { $ref: '#/channels/moduleRecord' }
    description: El módulo escribe su clave al arrancar. Rol docs-service, solo la clave `docs`.
```

Después (copia en Jiku):

```yaml
  registerModule:
    action: send
    channel: { $ref: '#/channels/moduleRecord' }
    description: El módulo escribe su clave al arrancar. Rol `docs`, solo la clave `docs`.
```

- Se cambia **solo** el token `docs-service` → `` `docs` `` (con backticks, el mismo estilo que ya
  usa la línea para la clave `` `docs` ``). Indentación (4 espacios), resto del texto y punto final
  intactos.
- El valor sigue siendo un escalar plano de YAML válido: los backticks no son caracteres especiales
  en esa posición (la línea de origen ya los contiene).
- `docs-service` aparece **una sola vez** en el archivo de origen (verificado con `grep -rn` sobre
  `conectores/jiku-docs/docs/`): después de la corrección, la copia tiene **cero** apariciones.

#### Estructura del contrato (debe quedar idéntica)

- `asyncapi: 3.0.0`; `info.title: Jiku — registro de módulos`; `info.version: 1.0.0`;
  `defaultContentType: application/json`.
- `servers.jiku-nats`: `host: '{natsHost}'`, `protocol: nats`, variable `natsHost` con default
  `nats.jiku.local:4222`.
- `channels.moduleRecord`: `address: '$KV.JIKU_MODULES.{module}'`; parámetro `module` con
  `enum: [docs]`; mensaje `moduleRecord` → `#/components/messages/ModuleRecord`.
- `operations`: `registerModule` (`action: send`) y `watchModules` (`action: receive`, descripción
  *"api, conectores y personas leen y observan el registro."*), ambas sobre `#/channels/moduleRecord`.
- `components.messages.ModuleRecord`: ejemplo `docs` con payload
  `{ module: docs, serviceName: jiku-docs, protocol: v1, registeredAt: '2026-10-24T12:00:00.000Z' }`.
- `components.schemas.ModuleRecord`: `type: object`,
  `required: [module, serviceName, protocol, registeredAt]`; propiedades:
  - `module`: `string`, `pattern: '^[a-z][a-z0-9-]{1,30}$'`
  - `serviceName`: `string`, `pattern: '^[a-z][a-z0-9-]{1,40}$'`
  - `protocol`: `string`, `pattern: '^v[0-9]+$'`
  - `registeredAt`: `string`, `format: date-time`
- `components.schemas.ModulesHttpResponse`: array de `{ module: string, status: enum
  [not_installed, unavailable, available] }` (`required: [module, status]`).

**Status:** Completed

#### Description
