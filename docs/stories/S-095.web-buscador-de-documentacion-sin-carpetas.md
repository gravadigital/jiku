# S-095: web: buscador de Documentación sin carpetas

**Status:** Completed
**Created:** 2026-10-26
**Source:** REQ-021

## Historia de Usuario

**Como** persona interna que usa Documentación,
**quiero** un solo buscador con filtros combinables (proyecto, cliente, tema, persona, texto, "Sin proyecto/cliente/tema"),
**para** encontrar y clasificar documentos sin navegar por carpetas.

## Criterios de Aceptación

### CA-1: Inicio sin filtros

**DADO** una persona interna en Documentación
**CUANDO** abre la pantalla sin filtros
**ENTONCES** ve el buscador, el selector "Todos / Visibles para el cliente", el orden, "En mis proyectos activos" (si hay datos) y "Editados recientemente" con "Cliente · Proyecto" por fila, y no ve "Vistas:", botón "Vistas", carpetas ni rutas

### CA-2: Sugerencias agrupadas

**DADO** el buscador con el filtro "Cliente EXO"
**CUANDO** escribe "vid"
**ENTONCES** ve "Buscar «vid» en títulos y contenido", los proyectos de EXO que coinciden y los temas con su conteo, con la coincidencia resaltada

### CA-3: Elegir una sugerencia

**DADO** sugerencias abiertas
**CUANDO** elige un proyecto con flechas y Enter
**ENTONCES** se agrega el token "Proyecto {nombre}" y la lista se filtra por ese proyecto

### CA-4: Búsqueda de texto

**DADO** texto escrito en el buscador
**CUANDO** presiona Enter
**ENTONCES** se agrega el token de texto y se muestran resultados con fragmentos resaltados, conteo y paginado

### CA-5: Quitar tokens

**DADO** varios tokens y el campo vacío
**CUANDO** presiona Backspace
**ENTONCES** se quita el último token (cada token también se quita con su ×; Esc cierra las sugerencias)

### CA-6: Sin proyecto, cliente o tema

**DADO** el buscador
**CUANDO** escribe "sin"
**ENTONCES** puede elegir "Sin proyecto", "Sin cliente" o "Sin tema", que filtran con `hasProject/hasClient/hasTopic: false`

### CA-7: Filtro de proyecto desde una ficha

**DADO** una URL `/docs?proyecto={id}&origen=proyecto` (o `requisito`/`tarea`)
**CUANDO** se abre
**ENTONCES** se ve el título "Documentos · {nombre}" y "Volver al proyecto" (requisito/tarea según el origen), que vuelve al detalle armando la ruta con el id del token, sin URL de vuelta en la query

### CA-8: Asignar proyecto

**DADO** el filtro "Sin proyecto"
**CUANDO** elige "Asignar proyecto" en una fila y un proyecto
**ENTONCES** se llama a `relations.update` con `add.projects`, el documento sale de la lista y el contenido no cambia fuera del bloque `jiku:`

### CA-9: Asignar sugerido

**DADO** una fila "Sin proyecto" con un candidato de `suggested-relations` con `projectId`
**CUANDO** elige "Asignar sugerido"
**ENTONCES** se asigna el proyecto sugerido (la fila muestra "Sugerido: {proyecto}" con su `reason`); sin candidato la fila ofrece "Asignar proyecto"

### CA-10: Conflicto al asignar

**DADO** `relations.update` responde `version_conflict`
**CUANDO** se asigna un proyecto
**ENTONCES** la persona ve un aviso y la fila se recarga

### CA-11: Estado en la URL

**DADO** cualquier combinación de filtros, orden y página
**CUANDO** se recarga o se comparte la URL
**ENTONCES** la vista se reconstruye igual, resolviendo los nombres de los tokens con lo que ya existe

### CA-12: Sin regresiones de módulo

**DADO** jiku-docs no disponible o el módulo apagado
**CUANDO** se abre Documentación
**ENTONCES** se ven los avisos actuales del módulo

## Technical Design

### Servicios Afectados

| Servicio | Impacto | Cambios Necesarios | Estado |
|----------|---------|-------------------|--------|
| web | Alto | `/docs` pasa a una pantalla con estados y filtros en la URL; `DocsSearchBar`, `DocsResults`, `DocumentRow`, `ClientProjectLabel`, `TopicPills`, `VisibilityPill`, `AssignProjectAction`, `ProjectPicker`; baja de `DocsBrowser`, `FolderBreadcrumb`, `useFolderContents`, `useFolderTrail`, `useRootFolders`, `foldersApi`, `utils/folders` | Done |

### Cambios de API

Consume (definidas en S-094): `GET /docs/documents`, `GET /docs/search`, `GET /docs/suggestions`, `GET /docs/documents/{id}/suggested-relations`, `POST /docs/documents/{id}/relations`. No agrega rutas.

### Cambios de Base de Datos

Ninguno.

### Diseño de la pantalla

**Estado en la URL.** Query params: `proyecto`, `cliente`, `tema`, `persona`, `q`, `requisito`, `tarea` (repetibles), `sinProyecto=1`, `sinCliente=1`, `sinTema=1`, `publico=1`, `orden`, `pagina`, `origen=proyecto|requisito|tarea`. Las pantallas 01-05 son estados de la misma ruta.

**Componentes** (estilo de `jiku.css` vía el DS de web; sin componentes nuevos en el DS en modo auto): `DocsSearchBar` (combobox con tokens, sugerencias agrupadas con resaltado, teclado flechas/Enter/Esc/Backspace, composición de `Input` `search`, chips y el menú de `Select`), `ToggleGroup` "Todos / Visibles para el cliente" (el DS no tiene checkbox), `Table` `light` con columnas Documento · Cliente · Proyecto · Actualizado · Editado por (`updatedByName`, o "—"); en el estado de proyecto la columna Cliente · Proyecto se reemplaza por Temas; en "Sin proyecto" queda Cliente.

**Paginado y orden.** Listados: cursor del servicio con Anterior/Siguiente (pila de cursores en memoria), `count=true`, 20 por página, orden "Más recientes" y "A–Z". Texto: `GET /docs/search` con limit 50, paginado en memoria, "Relevancia" y "Más recientes", "50+" si llega al tope.

**Sin proyecto.** Una consulta `suggested-relations` por fila visible (máximo 20 por página, `staleTime` 5 min); si alguna falla, la fila ofrece "Asignar proyecto" (`Select` `searchable` en la fila, sin diálogo propio).

**Filtros.** proyecto → `projectId`; cliente → `clientId`; tema → `topic`; persona → `person`; texto con Enter → `documents.search`; "Sin…" → `hasX=false`; "Solo visibles para el cliente" → `visibility=public`. Combinación con Y.

### Flujo de Interacción

#### Escenario: buscador con sugerencias y filtro de proyecto

**Trigger:** la persona escribe "vid" con el token "Cliente EXO" activo.

1. **[web — `DocsSearchBar`]**
   - Acción: Server Action `getDocsSuggestions`, debounce 200 ms, key `['docs','suggestions',q,clientId]`.
   - Output: `GET /api/docs/suggestions?q=vid&clientId=4`.
2. **[web]**
   - Acción: muestra "Buscar «vid»…" y los grupos con resaltado; Enter sobre un proyecto → `router.replace('/docs?cliente=4&proyecto=12')`.
3. **[web → api]**
   - Output: `GET /api/docs/documents?clientId=4&projectId=12&sort=-updatedAt&limit=20&count=true`.

**Outcome:** token agregado y lista filtrada con "Cliente · Proyecto" por fila.

**Manejo de errores:**
- Módulo no instalado → 404, la ruta hace `notFound()`.
- Módulo caído → 503 y aviso actual.

#### Escenario: "Asignar proyecto" / "Asignar sugerido"

**Trigger:** la persona abre `/docs?sinProyecto=1` y elige la acción de una fila.

1. **[web]** `GET /api/docs/documents?hasProject=false&limit=20&count=true` y, por fila, `GET .../suggested-relations`.
2. **[web → api]** `POST /api/docs/documents/{id}/relations { baseVersion: item.version, add: { projects: [12] } }`.
3. **[web]** invalida `['docs','documents',…]`; el documento sale de la lista.

**Outcome:** documento con proyecto (y su cliente).

**Manejo de errores:**
- 409 `version_conflict` → toast "El documento cambió; se actualizó la fila" y refetch.
- 409 `document_locked` → toast con `details.holderName`.
- 400 `invalid_relation` → toast de proyecto inválido.

### Flujos Afectados

- **buscador-de-documentacion** (ref: docs/flows/buscador-de-documentacion.md) — lado web del flujo nuevo.
- **documentos-desde-la-web** (ref: docs/flows/documentos-desde-la-web.md) — el panel de carpetas se reemplaza por el buscador.

### Consideraciones Técnicas

**Seguridad:**
- "Volver" sin URL arbitraria en la query (sin redirect abierto).
- No se toca sidebar, barra superior ni se agrega ⌘K.

**Performance:**
- Debounce de sugerencias; consultas de `suggested-relations` en paralelo con `staleTime`.

**Dependencias:**
- S-094 (rutas). Los componentes chicos `ClientProjectLabel`, `TopicPills` y `VisibilityPill` los crea la primera story que llegue (S-095, S-096, S-097) y las demás los reusan.
- Pendiente fuera de alcance: `access.changed` (la web no recibe eventos de docs en tiempo real).
- Pendiente: la búsqueda de temas es por prefijo (anotar en `known-limitations`).
- Si "Mis proyectos activos" no se puede resolver, la sección se omite.
