# S-096: web: lectura, historial y compartir

**Status:** Ready
**Created:** 2026-10-26
**Source:** REQ-021

## Historia de Usuario

**Como** persona interna que lee un documento,
**quiero** ver su Cliente / Proyecto, su historial de versiones y compartirlo sin referencias a carpetas, con los nombres reales de quienes lo editaron,
**para** entender el contexto del documento, recuperar versiones anteriores y compartirlo con seguridad.

## Criterios de Aceptación

### CA-1: Lectura sin ruta

**DADO** un documento en lectura
**CUANDO** se renderiza
**ENTONCES** no aparece "Ruta de almacenamiento" ni ninguna ruta; aparecen Cliente / Proyecto, temas, "En este documento", "Vinculado a" con nombres, visibilidad, versión y adjuntos, y el breadcrumb es "Documentación / {título}"

### CA-2: Sin frontmatter

**DADO** un documento con frontmatter
**CUANDO** se abre en lectura (y en la vista previa del editor)
**ENTONCES** el frontmatter no se ve como texto

### CA-3: Nombres del servicio

**DADO** un documento editado por la persona actual o por alguien con nombre
**CUANDO** se ve "Editado por", el aviso de lock o el historial
**ENTONCES** se muestra el nombre que manda el servicio (`updatedByName`, `createdByName`, `authorName`, `lock.holderName`, `details.holderName`), "vos" / "Estás editando" si el holder es la persona actual, "—" si el nombre es `null` ("otra persona" solo para un lock ajeno sin nombre)

### CA-4: Historial

**DADO** el historial de un documento con versiones compactadas
**CUANDO** se abre desde el botón "Historial"
**ENTONCES** lista las versiones con número, autor, fecha, tipo (Creación / Edición / Restauración), marca "Actual" y "Protegida", mensaje, y al pie "N versiones intermedias compactadas"

### CA-5: Versión compactada

**DADO** una versión pedida que fue compactada
**CUANDO** se abre
**ENTONCES** se informa que fue compactada y se ofrecen las versiones conservadas más cercanas (`previousAvailable` / `nextAvailable`)

### CA-6: Ver y restaurar una versión

**DADO** el historial
**CUANDO** elige "Ver" o "Restaurar"
**ENTONCES** "Ver" abre la lectura con `?version=N` (con aviso de versión anterior) y "Restaurar" pide confirmación y llama a `POST .../restore { fromVersion, baseVersion }`

### CA-7: Documento restringido

**DADO** un documento `restricted`
**CUANDO** se abre compartir
**ENTONCES** no se puede crear un link, el botón queda deshabilitado y se explica por qué

### CA-8: Compartir sin ruta

**DADO** el diálogo de compartir
**CUANDO** se abre
**ENTONCES** el subtítulo muestra "{título} · {Cliente} · {Proyecto}" en lugar de la ruta, y la lista muestra "Revocado (restringido)" para links revocados por pasar a restringido

## Technical Design

### Servicios Afectados

| Servicio | Impacto | Cambios Necesarios | Estado |
|----------|---------|-------------------|--------|
| web | Alto | `DocumentView` (cabecera, `DocumentToc`, `DocumentLinkedTo`, `DocumentProperties`), `utils/frontmatter.ts` (`stripFrontmatter`), `VersionHistoryPanel`, `ShareDocumentDialog`; baja de `DocumentBreadcrumb`, `personName`/`usePersons` para lock y autor | Pending |

### Cambios de API

Consume (definidas en S-094): `GET /docs/documents/{id}` (con `clientRefs`, `projectRefs`, `requirementRefs`, `taskRefs`, sin `folder`), `GET /docs/documents/{id}/versions`, `POST /docs/documents/{id}/restore`, rutas de compartir. No agrega rutas.

### Cambios de Base de Datos

Ninguno.

### Diseño de la pantalla

**Permisos en la interfaz.** `canEdit = !contentUrl`; `canShare = features.sharing && visibility !== 'restricted'`; el servicio sigue siendo la autoridad.

**Frontmatter.** `stripFrontmatter` (misma regex que opus-web) copiado a `web/src/features/docs/utils/frontmatter.ts`, aplicado antes de `DocumentContent` y del preview del editor.

**Cabecera (06).** Título, pill de visibilidad (Interno / Visible para el cliente / Restringido), "Cliente · Proyecto #n" (con `#id` de respaldo), temas, "Versión N · actualizado {fecha} por {updatedByName}" y botones Historial, Compartir (deshabilitado con nota en un restringido) y Editar. Se quita `boton-volver`.

**Historial (O-13).** Drawer lateral desde el documento con `GET /docs/documents/{id}/versions` paginado (`-version`), pie con `prunedVersionsCount`. Estados nuevos: viendo una versión anterior, versión compactada. "Restaurar" usa O-02.

**Compartir (O-12).** Lo abre toda persona interna; aviso de restringido en lugar de "la carpeta no permite".

### Flujo de Interacción

#### Escenario: historial y versión compactada

**Trigger:** la persona hace clic en "Historial".

1. **[web — `VersionHistoryPanel`]**
   - Output: `GET /api/docs/documents/{id}/versions?limit=50`.
2. **[web]**
   - Acción: lista con `authorName`, `kind`, `protected`, `message`; pie con `prunedVersionsCount`.
3. **[web → api]**
   - Acción: "Ver" en la versión 7 → `GET /api/docs/documents/{id}?version=7`.
4. **[api]**
   - Output: `404 { code: 'version_pruned', details: { requestedVersion: 7, previousAvailable: 5, nextAvailable: 9 } }`.
5. **[web]**
   - Acción: aviso y enlaces a las versiones 5 y 9.

**Outcome:** la persona navega a una versión conservada.

**Manejo de errores:**
- `version_pruned` en `restore` → mismo aviso.
- `version_conflict` al restaurar → aviso y recarga.

### Flujos Afectados

- **documentos-desde-la-web** (ref: docs/flows/documentos-desde-la-web.md) — lectura sin `folder`, aviso de lock con `holderName`, historial y restauración en la interfaz.
- **lectura-por-link-compartido** (ref: docs/flows/lectura-por-link-compartido.md) — un `restricted` no admite links.

### Consideraciones Técnicas

**Seguridad:**
- "Restringido" visible para todos, elegible solo por `admin`; la autoridad es jiku-docs.

**Performance:**
- Historial paginado; la lectura no hace consultas extra de nombres (vienen del servicio).

**Dependencias:**
- S-094 (rutas y contrato). Comparte `ClientProjectLabel`, `TopicPills` y `VisibilityPill` con S-095 y S-097.
- Bugs con test: frontmatter visible en el visor; "otra persona" en lock y "Editado por".
- Restaurar entra porque la api ya expone `restore`.
