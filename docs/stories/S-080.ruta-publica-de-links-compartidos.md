# S-080: Ruta pública de links compartidos

**Status:** Completed
**Created:** 2026-10-24
**Source:** REQ-016

## Historia de Usuario

**Como** persona de afuera de Jiku que recibe un link a un documento,
**quiero** abrirlo sin cuenta en una página de solo lectura,
**para** leer la documentación compartida sin que se exponga nada más de la aplicación.

## Criterios de Aceptación

### CA-20: Lectura anónima

**DADO** `JIKU_PUBLIC_URL=http://127.0.0.1:3100` y un token válido
**CUANDO** alguien sin sesión pide `GET http://127.0.0.1:3100/p/docs/{token}`
**ENTONCES** recibe 200 con una página HTML que contiene el `html` del documento y las cabeceras `Content-Security-Policy` sin scripts, `X-Robots-Tag: noindex`, `Referrer-Policy: no-referrer` y `Cache-Control: private, no-store`; la api llamó `shares.resolve` sin `actor`

### CA-21: Token inválido, indistinguible

**DADO** un token revocado, vencido o inexistente
**CUANDO** se pide `/p/docs/{token}`
**ENTONCES** responde 404 con una página genérica, idéntica en todos los casos

### CA-22: Host público

**DADO** `JIKU_PUBLIC_URL` sin configurar, o un pedido a `/p/docs/{token}` con `Host: localhost:3001` distinto del de `JIKU_PUBLIC_URL`
**CUANDO** se pide la ruta
**ENTONCES** responde 404 genérico sin llamar a jiku-docs

### CA-23: Rate limiting

**DADO** una misma IP
**CUANDO** hace 61 pedidos a `/p/docs/*` en un minuto
**ENTONCES** el pedido 61 recibe 429

### CA-24: Adjuntos del link

**DADO** un pedido a `/p/docs/{token}/attachments/{id}` válido
**CUANDO** se resuelve
**ENTONCES** la api llama `shares.attachment` y responde 302 a la URL prefirmada

### CA-S10: Módulo no disponible y host exclusivo

**DADO** el módulo `not_installed` (o `unavailable`)
**CUANDO** se pide `/p/docs/{token}`
**ENTONCES** responde 404 genérico (o 503 con una página genérica); y en el host público cualquier ruta que no sea `/p/docs/*` responde 404 (DD-10)

### Servicios Afectados

| docs/apis | Bajo | `api.yaml`: rutas públicas con `x-jiku-module: docs` | Done |

### Cambios de API

#### Endpoints Existentes a Modificar

**`api/config/public.ts`** — exención de la ruta pública `p/docs/` de `validateToken` (primera ruta sin sesión desde REQ-002).

#### Nuevos Endpoints

| # | Ruta | Llama a | Respuesta |
|---|---|---|---|
| 24 | `GET /p/docs/{token}` | `shares.resolve { token }` sin `actor` | `200 text/html` |
| 25 | `GET /p/docs/{token}/attachments/{id}` | `shares.attachment { token, attachmentId }` sin `actor` | `302 Location: downloadUrl` |

Cadena, en orden: (1) `JIKU_PUBLIC_URL` sin configurar o `Host` distinto → 404 genérico sin llamar a nada; (2) rate limit 60/min/IP → 429; (3) token que no cumple `^jds_[A-Za-z0-9_-]{43}$` → 404 genérico sin llamar al bus; (4) módulo `not_installed`/`incompatible` → 404 genérico, `unavailable` → 503 página genérica; (5) `share_not_found` o cualquier otro error → 404 genérico idéntico.

Cabeceras de **toda** respuesta de `/p/docs/*` (200, 404, 429, 503):

```
Content-Security-Policy: default-src 'none'; img-src 'self' https: data:; style-src 'unsafe-inline';
                         base-uri 'none'; form-action 'none'; frame-ancestors 'none'
X-Robots-Tag: noindex
Referrer-Policy: no-referrer
Cache-Control: private, no-store
X-Content-Type-Options: nosniff
```

`img-src https:` por H-5: las imágenes redirigen (302) al storage S3 y la CSP se evalúa también contra el destino.

**Página (DD-12):** plantilla HTML mínima propia: `<title>` escapado, `<meta name="robots" content="noindex">`, estilos inline mínimos y el `html` de `shares.resolve` (ya sanitizado por jiku-docs; la api no vuelve a sanitizar). Si viene `htmlUrl` (> 256 KiB) la api lo descarga del lado del servidor (texto, ≤ 5 MiB) y lo incrusta. Sin cookies.

### Cambios de Base de Datos

Ninguno.

### Variables de entorno

| Variable | Servicio | Default | Para qué |
|---|---|---|---|
| `JIKU_PUBLIC_URL` | api | vacía | Base del host público. Vacía → `/p/docs/*` 404 y `features.sharing: false` |
| `API_TRUST_PROXY` | api | vacía | Valor de `trust proxy`; en producción `1` |
| `DOCS_PUBLIC_DOMAIN` | deploy | vacía | Host público sin esquema; el compose lo suma a `VIRTUAL_HOST`/`LETSENCRYPT_HOST` y arma `JIKU_PUBLIC_URL`. **Esta story verifica la interpolación anidada del compose**; si no la soporta, se declaran las dos variables por separado |

Local: `JIKU_PUBLIC_URL=http://127.0.0.1:3100` (host distinto de `localhost`).

### Flujo de Interacción

#### Escenario: lectura anónima por link (CA-20 a CA-24)

**Trigger:** visitante sin sesión abre `{JIKU_PUBLIC_URL}/p/docs/{token}`.

1. **[api — public-docs-get.ts]** host ✓ → rate limit ✓ → formato del token ✓ → módulo `available` ✓.
2. **[api → jiku-docs]** `shares.resolve { token }` sin `actor`.
3. **[jiku-docs]** `{ shareId, documentId, title, version, html, attachments }` (o `htmlUrl`).
4. **[api]** `200 text/html` con las cabeceras de solo lectura.
5. **[navegador]** las imágenes piden `/p/docs/{token}/attachments/{id}` → `shares.attachment` → 302 a S3.

**Outcome:** el documento se lee sin cuenta ni cookies.

**Manejo de errores:**
- Cualquier fallo de token → el mismo 404; pedido 61 → 429; módulo caído → 503 genérico.

### Consideraciones Técnicas

**Seguridad:**
- Es la única ruta sin credencial del producto: merece revisión propia.
- El log de acceso (`express-winston`) registraría el token en la URL: la ruta se excluye del logger de requests o se loguea enmascarada (`/p/docs/jds_…`).
- En el host público la api no sirve nada más (DD-10); el host propio evita compartir cookies con la aplicación.
- El token de 256 bits hace inviable la enumeración.

**Performance:**
- Rate limit en memoria por réplica: con N réplicas el límite efectivo es 60·N/min (R-5, se documenta en S-085).
- Sin `trust proxy` detrás del ingress todas las IP serían la del proxy.

**Dependencias:**
- Depende de S-077. Dependencia nueva de npm: `express-rate-limit`.
