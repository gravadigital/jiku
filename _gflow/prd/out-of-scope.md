# Fuera de alcance

| Fuera de alcance | Origen |
|---|---|
| Integraciones con gestores externos de tareas o código (GitLab, GitHub, Jira): se eliminaron junto con su configuración y su sincronización | inicial |
| Notificaciones por Mattermost u otro chat: se eliminaron; del proyecto solo queda la propiedad `mattermost_group_name` como texto | inicial |
| Recibir respuestas por mail ni hilos de mail por requisito o tarea: se eliminaron | inicial |
| Notificaciones por un canal que no sea email (en la aplicación, push) | inicial |
| Notificaciones de tareas y suscripción a tareas desde el producto | inicial |
| Etapas de tareas: el concepto se eliminó | inicial |
| Borrar clientes, proyectos, requisitos o tareas: la baja de un requisito, una tarea o un proyecto es su estado `cancelado` | inicial |
| Dar de alta, editar o dar de baja personas, usuarios, permisos de proyecto o personas de un proyecto desde el producto: se cargan fuera | inicial |
| Alta de usuarios y onboarding de clientes desde el producto: el aviso de ingreso no registra a nadie | inicial |
| Gestión de credenciales y recuperación de acceso: las resuelve Zitadel | inicial |
| Editar una carga de horas o una ausencia: solo se cargan y se borran | inicial |
| Editar los ajustes del sistema (política de archivos, notificaciones, horas por día) desde el producto: se cambian en la base | inicial |
| Retención y limpieza de archivos: no hay proceso que retire archivos pendientes ni marque archivos para borrar | inicial |
| Búsqueda semántica de documentación desde el producto: la búsqueda es solo de texto | inicial |
| Internacionalización: las dos superficies están solo en español | inicial |
| Gestión interna en móvil: es solo de escritorio | inicial |
| Tema oscuro en el Portal de clientes (Gestión interna sí lo tiene) | inicial |
| Registro de auditoría de accesos, permisos o borrados: solo existe el historial de cambios de requisitos y tareas | inicial |
